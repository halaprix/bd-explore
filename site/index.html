01 — the query

The answer is in the notes, not the titles.

bd search covers titles. bd query is structured-only. Nothing in the stock CLI searches notes, comments, or close reasons — where a mature store keeps most of its knowledge.

bd-explore runs Porter-stemmed FTS5 over every prose field a bead carries, ranks with BM25, and prints the winners whole — with their 1-hop neighborhood so you see what blocks what before touching anything.

Every hit is stamped [STATUS · P<n> · type · updated …] — staleness is first-class, and closed history ranks below open work at equal relevance.

filters compose with free text
$ bd-explore "hash refresh status:open type:task priority:1"
$ bd-explore "swap oracle epic:rpm5"
$ bd-explore -n 3 --budget 16000 "database migration"
status:open · in_progress · closed · deferred · all
type:bug · feature · task · epic · chore
priority:0–4, or P0–P4
epic:beads belonging to an epic, by id or suffix
id:match bead ids by substring
02 — the grammar

Codegraph-style field filters.

Mix filters into the question the way you'd type it. Unknown prefixes fall through to free text, so searching for “PR #214: fix auth” just works.

The output budget (default 24 000 characters) is a hard cap, enforced to the character — built for agent context windows.

03 — the graph

See the whole chain before you pull a thread.

Beads are beads on threads: explicit dependency edges, plus mention edges mined from prose (“see SYRP-118”) and GitHub #NNN references.

upstream blockers, downstream dependents, epic ancestry — one flag, the full transitive closure.

04 — the server

An MCP server with zero dependencies.

The same pipeline is exposed as a stdio JSON-RPC 2.0 MCP tool, bd_explore — NDJSON and Content-Length framing, pure standard library.

The installer detects your platforms, adds the MCP config, and injects marker-fenced instructions it can cleanly update or remove later.

Everything is derived and disposable: a SQLite FTS5 cache under ~/.cache/bd-explore, rebuilt automatically when your .beads export changes. The store stays the sole source of truth.

Two commands to first answer.

Requires Python 3.10+ with SQLite FTS5 (standard in CPython) and a repo with a .beads/ store.

install
# install from source
$ pip install git+https://github.com/halaprix/bd-explore

# or: clone and use the shell installer (~/.local/bin + agent setup)
$ git clone https://github.com/halaprix/bd-explore && cd bd-explore && ./install.sh

# first question
$ bd-explore "what do we know about auth refactor"
